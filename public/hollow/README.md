# Visuels Hollow en attente

Les images originales restent présentes sur le site existant. Leur publication dans ce dépôt GitHub public attend l’accord explicite de leur propriétaire, demandé après le refus du contrôle automatique d’approbation.

Aucun pixel des visuels d’origine n’est inclus dans ce dépôt. Le manifeste `assets-manifest.json` recense seulement les noms, tailles et empreintes attendus par le module. Les chemins du code restent prêts pour ces ressources ; les illustrations ne seront pas affichées dans une installation neuve du dépôt tant que leur ajout n’est pas autorisé et réalisé.
